# Desafio-tecnico---LACEDA
Desafio prático de Engenharia de Dados voltado à integração e geocodificação de endereços. O objetivo é desenvolver uma solução computacional capaz de localizar, na base do CNEFE Bahia, o setor censitário correspondente a 100 endereços com diferentes níveis de qualidade, gerando uma base final com os setores identificados e os casos não localizados
